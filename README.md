#  Kawaii Pixel Calculator

A custom pixel-art calculator built with HTML, CSS, and JavaScript.

## ✨ Features

- Basic arithmetic operations
- Decimal number support
- Backspace functionality
- Clear functionality
- Keyboard controls
- Calculation history
- Clear history
- Dark mode
- Saved theme preference
- Responsive design
- Custom pixel-art buttons
- Button animations
- Error handling

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Fonts

## 🎨 Design

The calculator uses a kawaii/Y2K-inspired pixel-art design with a pink and purple color palette and custom graphical button assets.
